# QGIS_Honduras

En este proyecto se realizaron filtros para diferentes capas con información geográfica de Honduras, estas eran: departamentos, municipios, centros educativos, caseríos, cuencas, subcuencas y puntos de Orica. Este último era la distinción especial del proyecto ya que se nos dio información específica del municipio de Orica, aunque también contaba con puntos de municipios aledaños, los cuales tenían descripciones sobre lo que eran, como aldeas, centros educativos, postas policiales entre otras. El punto del proyecto era lograr utilizar filtros de forma en que se vea cierta información en el mapa de Honduras, como darle click a un departamento para que salgan los municipios, o darle click a un municipio para que salgan los centros educativos de dicho municipio, entre otras cosas similares. Los datos para este proyecto eran las diferentes capas que se utilizaban para mostrar la información, esta se comprimió a un archivo zip ya que el folder completo pesaba más de lo que acepta github por commit y se llama Shapefiles.
